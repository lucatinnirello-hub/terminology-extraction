Terminology Job Flow

How a job moves from the web page to a finished glossary: what the page sends n8n, what gets uploaded and downloaded, where each decision is made, and what happens when something goes wrong.

Web page (browser) Google: Apps Script, Sheets, Drive Cloudflare n8n Anthropic API Failure path Optional or reply
Starts when you submitThe page sends n8n one request through Cloudflare. n8n replies within seconds and keeps working.
Two sets of access checkedThe page runs as you, so Drive checks your access. n8n checks its own before accepting.
AI review needs three yesesRequested on the page, client approval ticked, and the client not on n8n's restricted list.
1 · THE PARTS

Who talks to whom

The page talks to n8n directly, through Cloudflare. Files never travel in the request: n8n reads and writes them in Drive.

2 · UPLOAD

Checking folders and submitting

Folders are checked twice: when the link is pasted, so problems show up early, and again on submit. Uploaded files go to the working folder first, one call per file, so the request to n8n stays small.

3 · STATUS

The states a job moves through

A refused job never reaches the log: the reason is shown on the page and nothing has been started.

4 · PROCESSING

What n8n does with a request

Everything in the top band happens while the page waits, in a second or two. After the 202 reply, each red exit writes a plain-language reason to the job's row.

5 · DATA

Where the content goes

Client files stay in Google Drive. Content leaves Google only for the AI review, and only in excerpts.
